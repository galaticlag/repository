# repository

Personal distribution point for private, sideloaded builds.

- **Android** — release APKs are attached to the [Releases](../../releases) of this repo and
  can be tracked with [Obtainium](https://github.com/ImranR98/Obtainium).
- **iOS** — unsigned IPAs are attached to pre-releases and listed in a
  [SideStore](https://sidestore.io) source: `https://galaticlag.github.io/repository/apps.json`.

Releases and `apps.json` are generated by CI or by the maintainer's scripts. There is nothing
to read or contribute here.
